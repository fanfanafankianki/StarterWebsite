About this Project

This project is a comprehensive automated DevOps environment designed to streamline and enhance the continuous integration and continuous deployment (CI/CD) process.

With this project, we aimed to replicate the optimal configuration of a company's production setup, ensuring efficient and reliable application development, testing, deployment and monitoring.

Our solution integrates popular tools and technologies to ensure seamless automation, scalability, and monitoring of software deployments.

The solution is designed to reduce manual intervention, thereby minimizing errors and increasing productivity.

Used Technologies

Infrastructure
· AWS EC2 instances were used to host the entire setup.
· Terraform and Ansible, integrated into Jenkins pipelines, automate the configuration and management of EC2 instances and the creation and configuration of Kubernetes nodes.
· The environment is orchestrated with Kubernetes (K8s), utilizing Helm with Flux for efficient package management and application deployment.
CI/CD
· CI/CD was created with the use of Jenkins pipelines.
· Each push to the repository automatically triggers the creation of a Docker image, streamlining the test process.
· Sonarqube and Cypress are used to test code quality and proper behavior of new deployments.
· Sorry Cypress Dashboard with Minio allows checking the quality and progress of test execution.
· FLUX deploys the validated Docker image to the development environment, maintaining a smooth and efficient workflow.
Application Components
· The application environment is built with an Angular frontend and a Django backend, both served by Nginx.
· The backend also utilizes Memcached for caching database queries and RabbitMQ for message queuing.
· The database is PostgreSQL, accompanied by the pgAdmin dashboard for management and monitoring.
Monitoring
· Prometheus deployments and Grafana dashboards are used for monitoring.
· All applications expose metrics, which are scraped by Prometheus.
· Prometheus is integrated with Grafana, enabling data visualization.
